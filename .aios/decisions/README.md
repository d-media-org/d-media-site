# Decisions Index

## Purpose
Reserve this folder for future detailed Architecture Decision Records and operating decisions.

## Scope
Future decisions may cover deployment strategy, routing changes, SEO/GEO policy, brand rules, and tooling changes.

## Rules
- Keep each future decision in its own Markdown file.
- Include context, decision, consequences, and revision history.
- Do not rewrite history; supersede decisions explicitly.

## Examples
- A future ADR may document replacing or retiring the root Next.js app.
- A future ADR may document a Cloudflare runtime change.
