# Memory Index

## Purpose
Reserve this folder for durable project memory approved for future AI reuse.

## Scope
Future memory entries may capture recurring project facts, human preferences, validated constraints, and recurring pitfalls.

## Rules
- Store only durable, non-secret, project-relevant memory.
- Do not store private client data.
- Mark uncertain memory as `Needs human validation`.
- Prefer root documents for canonical rules.

## Examples
- A future memory note may record a confirmed deployment owner.
- A future memory note may record a repeated QA failure pattern.
